# Threads Link Preview Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve link previews for all pages shared on Threads (and by extension Facebook/Instagram, which use the same Meta crawler infrastructure).

**Architecture:** Extend the existing Vite plugin system that generates blog post OG images to also generate a default branded template image for non-blog pages. Enhance the SEO.svelte component to include all required Open Graph and Twitter Card meta tags. Standardize meta tag approach across all pages.

**Tech Stack:** SvelteKit, svelte-meta-tags, satori, @resvg/resvg-js, existing vite-plugin infrastructure

	interface Props {
		title: string;
		description: string;
		canonical: string;
		openGraphType?: 'website' | 'article';
		twitterCard?: 'summary' | 'summary_large_image';
		ogImage?: string;

		twitterSite?: string;

	const fontData = readFileSync(fontPath);

	const logoPath = join(root, 'static', 'favicon.png');
	const logoData = readFileSync(logoPath);
	const logoBase64 = logoData.toString('base64');

	const year = new Date().getFullYear().toString();

	const svg = await satori(
		{
			type: 'div',
			key: null,
			props: {
				style: {
					width: '1200px',
					height: '630px',
					background: '#faf9f7',

					{
						type: 'div',

							style: {
								display: 'flex',
								alignItems: 'center',
								justifyContent: 'space-between',
								width: '100%'
							},
							children: [
								{
									type: 'div',
									props: {
										style: {
											display: 'flex',
											alignItems: 'center',
											gap: '12px'
										},
										children: [
											{
												type: 'img',
												props: {
													src: `data:image/png;base64,${logoBase64}`,
													style: { width: '40px', height: '40px' }
												}
											},
											{
												type: 'div',
												props: {
													style: {
														fontSize: '18px',
														color: '#78716c',
														letterSpacing: '0.05em',
														textTransform: 'uppercase'
													},
													children: 'Olamaelcu'
												}
											}
										]
									}
								},
								{
									type: 'div',
									props: {
										style: { fontSize: '14px', color: '#a8a29e' },
										children: year
									}
								}
							]
						}
					},
					{
						type: 'div',
						props: {
							style: {
								display: 'flex',

											fontSize: '64px',
											fontWeight: 400,
											color: '#1c1917',
											lineHeight: 1.1,
											margin: 0
										},
										children: pageTitle
									}
								},
								pageDescription
									? {
											type: 'p',
											props: {
												style: {
													fontSize: '24px',
													color: '#78716c',
													lineHeight: 1.4,
													margin: 0
												},
												children: pageDescription
											}
										}
									: { type: 'span', props: { children: '' } }
							]
						}
					},
					{
						type: 'div',
						props: {
							style: {
								width: '100%',
								height: '2px',

						}
					}

			width: 1200,

			fonts: [{ name: 'Kalnia', data: fontData, weight: 400, style: 'normal' }]

	return resvg.render().asPng();
}
